# Knowledge Base Entry: Product Feed Translation Add-on causes feed auto-refresh to stop scheduling

## 🎯 Executive Summary
**The Issue:** When the Product Feed Translation Add-on plugin is active, only one feed gets a scheduled refresh interval created — all other feeds silently lose their auto-refresh schedule.
**The Fix:** Install the provided hotfix zip, then manually refresh the feeds once to re-register the Action Scheduler entries.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** feeds not auto-refreshing, only one feed updating automatically, Action Scheduler missing pending feed actions, Product Feed Translation Add-on, feeds require manual refresh to work
>
> **Steps to solve:**
> 1. Confirm the customer has Product Feed Translation Add-on installed and active — go to Plugins and check.
> 2. Ask the customer to verify by visiting WooCommerce > Status > Scheduled Actions > Pending Actions and searching for "feed". If only one feed has a scheduled entry, this is the bug.
> 3. Provide the hotfix zip (linked via internal Limewire/release channel) and ask them to install it via Plugins > Add New > Upload.
> 4. After installation, have them manually refresh all affected feeds once. This triggers the plugin to re-register the missing Action Scheduler entries.
> 5. Confirm by revisiting Scheduled Actions — all feeds should now show pending refresh entries.
> 6. If the customer prefers to wait, an official version release resolves this within 2–3 days.
