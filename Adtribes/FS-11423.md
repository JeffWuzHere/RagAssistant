# Knowledge Base Entry: Multiple additional_image_link fields creating invalid field names (_b, _c) in Facebook Catalog feed

## 🎯 Executive Summary
**The Issue:** Adding multiple `additional_image_link` rows in Field Mapping caused the plugin to append suffixes (`_b`, `_c`) creating invalid field names like `additional_image_link_b` that Meta/Facebook does not recognize.
**The Fix:** Use the "All images comma-separated" mappable field for a single `additional_image_link` attribute. This outputs all gallery images in one comma-separated tag, which is the correct Meta format.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** additional_image_link_b not recognized, Meta catalog image import failing, multiple gallery images in Facebook feed, additional images Facebook catalog, Meta does not recognize additional_image_link_b, extra images in feed rejected
>
> **Steps to solve:**
> 1. In Field Mapping, remove all the duplicate `additional_image_link` rows that are creating `_b`, `_c`, etc. suffixes.
> 2. Add a **single** `additional_image_link` row.
> 3. Map it to the **"All images comma-separated"** mappable field (search for it in the field value dropdown).
> 4. Regenerate the feed and verify the output — the tag should contain all gallery image URLs separated by commas within a single `<additional_image_link>` or `additional_image_link` field.
> 5. In Facebook/Meta Catalog Manager, trigger a resync or manually refresh the catalog to re-import the corrected images.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- This is a common misconception about how multiple values work in XML feeds. Adding multiple rows for the same attribute causes the plugin to suffix the duplicates — the correct approach for comma-separated multi-value fields is the dedicated "comma-separated" mappable field.
- The same "All images comma-separated" approach applies for Google Merchant Center feeds using the `.txt` format (where `additional_image_link` accepts comma-separated values per Google's spec: https://support.google.com/merchants/answer/6324370).
- For XML format feeds (Google Shopping), you need separate `<additional_image_link>` tags — in that case, multiple rows with suffixes is actually correct for Google but not for Meta/Facebook.
