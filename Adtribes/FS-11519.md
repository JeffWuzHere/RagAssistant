# Knowledge Base Entry: Feed showing store default currency for all products despite multi-currency setup — unsupported currency switcher plugin

## 🎯 Executive Summary
**The Issue:** Three feeds set up for GBP, EUR, and USD were all outputting prices in GBP (the store's default currency). The customer was using a currency switcher plugin that is not integrated with Product Feed Elite.
**The Fix:** Switch to a supported currency switcher plugin. Only Aelia Currency Switcher, CURCY, and WPML are officially integrated. Unsupported plugins result in all feeds defaulting to the store's base currency.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** feed showing wrong currency, all feeds in GBP or base currency, multi-currency not working in feed, currency switcher not reflected in feed, USD EUR feed showing base currency prices
>
> **Steps to solve:**
> 1. Ask the customer which currency switcher plugin they are using.
> 2. Check against the supported list:
>    - **Aelia Currency Switcher**: https://adtribes.io/aelia-currency-switcher-feature/
>    - **CURCY (WooCommerce Multi Currency)**: https://adtribes.io/curcy-currency-switcher-feature/
>    - **WPML**: https://adtribes.io/wpml-support/
> 3. If their plugin is not on this list, explain that Product Feed Elite cannot read its converted prices — the feed will always output the store's default WooCommerce currency.
> 4. The fix is to switch to one of the three supported plugins. There is no snippet or workaround to add compatibility for unsupported switchers.
> 5. If they switch plugins, they may need to recreate or reconfigure the currency feeds.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- The integration with currency switchers requires specific hooks that each supported plugin exposes. Without that, the feed engine has no way to retrieve the converted price for a given currency.
- Customers often don't realize their currency switcher is "unsupported" until they see this behavior. When diagnosing, always check currency switcher compatibility early if multi-currency feeds are involved.
- The feed dropping to 0 products (the customer's second issue) was a separate problem and was not resolved in this ticket — do not conflate the two issues.
