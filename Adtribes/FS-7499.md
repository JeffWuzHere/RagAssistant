# Knowledge Base Entry: Static Value option not findable in Field Mapping after UI update — use the search input

## 🎯 Executive Summary
**The Issue:** After a UI update to the feed editor, customers could no longer find or select the "Static Value" option in the Field Mapping value dropdown — the dropdown only showed product/meta fields from the database.
**The Fix:** The Static Value option is still available — type "Static Value" (or "static") into the value dropdown's **search input** to filter and find it. It does not appear by default in the visible list.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** static value not showing, can't enter free text in feed, static value missing from dropdown, how to add fixed text to feed field, custom free text in feed mapping, static value option gone, same value for all products
>
> **Steps to solve:**
> 1. Open the feed editor and go to the **Field Mapping** tab.
> 2. For the attribute row where you want a static/fixed value, click the value dropdown on the right side.
> 3. Instead of scrolling, **type "static"** or **"Static Value"** in the search input at the top of the dropdown.
> 4. The "Static Value" option will appear — select it.
> 5. A text input field will appear where you can type the fixed value (e.g., `DE:0,BE:0` for shipping, or `new` for condition).
> 6. Save and refresh the feed.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- This is a discoverability issue introduced by the new dropdown UI — the list is now search-driven rather than pre-populated, so options not matching the initial view require a search.
- Feeds created **before** the UI update retain their static value mappings and show them correctly. Only **new** field mapping rows require the search-to-find pattern.
- The Static Value option works the same as before: one value applies uniformly to all products in the feed for that attribute.
- This applies to any "hidden" mappable field — if a customer says a field option is "missing," have them try typing it in the search first before concluding it was removed.
