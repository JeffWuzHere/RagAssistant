# Knowledge Base Entry: All feeds broken after plugin update — WooCommerce 3.7.2 below minimum requirements; rollback option

## 🎯 Executive Summary
**The Issue:** All feeds stopped working after a Product Feed Pro/Elite update. The site was running WooCommerce 3.7.2 (released ~2019) with PHP 7.4 — both far below the minimum supported versions.
**The Fix:** Update WooCommerce (and PHP) to supported versions. If updating is not immediately possible, roll back Product Feed Pro/Elite to the pre-November-12 versions and also roll back WooCommerce to a compatible older version.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** feeds stopped working after update, all feeds broken, WooCommerce version incompatibility, plugin requires newer WooCommerce, rollback plugin version, feeds error after update, PHP 7.4 not supported
>
> **Steps to solve:**
> 1. Check the customer's System Status Report for WooCommerce and PHP versions. Minimum supported: **WooCommerce 6.x+**, **PHP 8.1+**.
> 2. If they are on an unsupported version (e.g., WooCommerce 3.x, PHP 7.4):
>    - **Preferred fix:** Update WooCommerce to the latest version from https://developer.woocommerce.com/changelog/ and request PHP 8.1+ from their hosting provider.
>    - **Temporary rollback:** Provide the pre-November-12 Product Feed Elite ZIP from https://limewire.com/d/skzzJ and Pro from https://wordpress.org/plugins/woo-product-feed-pro/advanced/. They may also need to downgrade WooCommerce from https://developer.woocommerce.com/releases/.
> 3. Warn the customer: running on old versions means they miss bug fixes and security patches. Rollback is a temporary measure only.
> 4. Confirm the customer installs the older version via FTP or WP Admin > Plugins > Add New > Upload Plugin, replacing the existing plugin file.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- WooCommerce 3.7.2 is from approximately 2019. Customers running severely outdated WooCommerce may not be able to update due to theme/plugin compatibility constraints on their existing site.
- When rolling back, both the Product Feed plugin AND WooCommerce may need to be downgraded together — rolling back only the feed plugin may not be sufficient if WooCommerce itself introduced breaking changes.
- Product Feed Pro old versions are available at https://wordpress.org/plugins/woo-product-feed-pro/advanced/
- WooCommerce old versions are available at https://developer.woocommerce.com/releases/
- Always caveat rollbacks with a warning about missed security fixes.
