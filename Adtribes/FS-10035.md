# Knowledge Base Entry: OpenAI JSONL feed generating with error status — caused by outdated WooCommerce (9.x); also Include Variations required for variable products

## 🎯 Executive Summary
**The Issue:** An OpenAI JSONL format feed was generating with an error status. The root cause was WooCommerce version 9.x — which is below the minimum supported requirement. After updating WooCommerce to 10.x, the feed generated successfully, but only simple products appeared. Variable product variations were absent because "Include Product Variations" was not enabled.
**The Fix:** Update WooCommerce to 10.x+, then enable "Include Product Variations" on the feed's General settings.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** OpenAI feed error, JSONL feed not generating, OpenAI product feed status error, feed error status OpenAI, variable products missing OpenAI feed, only simple products in feed
>
> **Steps to solve:**
> 1. Check the System Status Report for the WooCommerce version. Minimum supported is **WooCommerce 10.x** for OpenAI JSONL feeds.
> 2. Ask the customer to update WooCommerce to the latest version.
> 3. After updating, refresh the OpenAI JSONL feed and confirm the error status clears.
> 4. If the feed generates but only shows simple products (variations missing):
>    - Go to the feed's **General settings** tab.
>    - Enable **"Include Product Variations"**.
>    - Save and refresh the feed.
> 5. Verify the JSONL output contains both simple products and variation entries.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- OpenAI JSONL is a newer feed format added in more recent plugin versions. It relies on WooCommerce 10.x APIs that were not available in 9.x, hence the error.
- The "Include Product Variations" setting must be enabled for any feed that should contain variable product variations — without it, only parent/simple products are included. This catches many customers off guard because their store is primarily variable products.
- For JSONL/OpenAI feeds specifically, if a customer says "feed is empty" or "only a few products," check: (1) WooCommerce version compatibility, and (2) whether Include Variations is enabled.
- This diagnosis path (update WooCommerce → fix error, then enable variations → fix missing products) is a two-step fix that looks like two separate problems but both stem from setup gaps.
