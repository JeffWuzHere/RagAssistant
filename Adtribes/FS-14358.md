# Knowledge Base Entry: _load_textdomain_just_in_time called incorrectly — outdated plugin version due to expired license

## 🎯 Executive Summary
**The Issue:** A customer was receiving a PHP notice: "Function _load_textdomain_just_in_time was called incorrectly. Translation loading for the woo-product-feed-pro domain was triggered too early."
**The Fix:** This notice was introduced in WordPress 6.7.0 and is triggered by outdated plugin code; the customer's license had expired in October 2025, meaning they were running an old version of the plugin — updating to the latest version resolves the notice.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** _load_textdomain_just_in_time, translation loading too early, called incorrectly, woo-product-feed-pro domain error, PHP notice translation
>
> **Steps to solve:**
> 1. Check the customer's license expiry date. This notice almost always means they're on an old plugin version.
> 2. If the license is expired, inform the customer that to get the latest version (which fixes this notice), they need to renew their license.
> 3. If the license is active but they're still seeing it, ask them to check **WooCommerce > Status** or the **Plugins** page to confirm they are running the latest version of Product Feed Pro/Elite.
> 4. Direct them to the changelog for reference: adtribes.io/knowledge-base/is-there-a-changelog-for-adtribes-plugins/
> 5. Note: this notice does not break functionality in most cases, but it indicates the plugin is running outdated code.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- WordPress 6.7.0 added the `_load_textdomain_just_in_time` deprecation notice. Any plugin that loads translations before the `init` hook will trigger it.
- This notice in woo-product-feed-pro was fixed in a newer plugin release. An expired license means the site is stuck on an older version.
- Expired license → outdated plugin → PHP notice is the standard chain here. Renewal solves it.
