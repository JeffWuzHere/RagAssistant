# Knowledge Base Entry: Automatic refresh produces fewer products than manual refresh — bug fixed in Product Feed Pro v13.4.5

## 🎯 Executive Summary
**The Issue:** Automatic (scheduled) feed refreshes produced fewer products than a manual refresh on the same feed — resulting in incomplete feeds being served to ad platforms.
**The Fix:** Update **Product Feed Pro to v13.4.5** where this bug was fixed. Manual refresh continues to work correctly on all versions.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** automatic refresh missing products, scheduled refresh fewer products, auto-refresh not all products, hourly refresh less products than manual, cron refresh incomplete feed, feed missing products on schedule
>
> **Steps to solve:**
> 1. Confirm the pattern: manual refresh → correct product count; automatic/scheduled refresh → fewer products.
> 2. Ask the customer to update **Product Feed Pro to v13.4.5 or later**. The bug was specifically fixed in that release.
> 3. After updating, allow the next scheduled refresh to run and verify the product count matches the manual refresh count.
> 4. If the customer needs an immediate fix while waiting for the update to be tested: trigger a manual refresh as a stopgap.
