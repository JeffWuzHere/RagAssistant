# Knowledge Base Entry: WPML language selector missing from feed General settings — enable WPML support toggle or update plugin

## 🎯 Executive Summary
**The Issue:** Customer had WPML-based multi-language feeds working, then a plugin update caused the language selector to disappear from the feed's General settings tab, and existing feed filters also disappeared.
**The Fix:** Go to **Product Feed Elite > Settings** and ensure the **WPML support** toggle is enabled. Cycling the toggle (disable then re-enable) can also restore the option. Alternatively, update the plugin.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** WPML language option missing, can't select language for feed, language selector not showing, WPML feed language disappeared, feed language setting gone, WPML support not working after update
>
> **Steps to solve:**
> 1. Go to **Product Feed Elite > Settings**.
> 2. Locate the **WPML Support** option and confirm it is enabled.
> 3. If it was already enabled, try cycling: disable it, save, then re-enable it and save again.
> 4. Go back to the feed's **General** tab and confirm the language selector now appears.
> 5. If the selector is still missing, ensure the plugin is updated to the latest version — outdated versions may not expose the WPML setting correctly.
> 6. If filters also disappeared from existing feeds, recreate them — this appears to be a one-time data migration issue resolved by toggling the WPML setting.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- The WPML language selector on the feed General tab is only displayed if the WPML support option is active in Product Feed Elite > Settings. It is not auto-enabled even if WPML is installed.
- After cycling the toggle, old feeds may retain their data. If filters are missing, the customer may need to recreate them — this is rare and typically a one-time issue after a version upgrade.
- This is distinct from the TranslatePress language issue (FS-8904) — WPML and TranslatePress have separate integration settings and separate bugs.
