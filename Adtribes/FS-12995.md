# Knowledge Base Entry: Cannot bypass "include lowest priced variation" setting for a single product — workaround with two feeds

## 🎯 Executive Summary
**The Issue:** The "Only include lowest priced product variation(s)" setting applies at the feed level — there is no per-product override or rule to exempt a specific product from this restriction.
**The Fix:** Split into two feeds: Feed 1 uses the lowest-price option with an exclusion rule for the exception product; Feed 2 targets only that product and includes all variations. Use both feeds together.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** lowest priced variation per product exception, include all variations for one product, bypass lowest price variation rule, exclude single product from lowest price variation setting
>
> **Steps to solve:**
> 1. Confirm this is the correct limitation: "Only include lowest priced product variation(s)" is a **feed-level** setting — it cannot be toggled per-product.
> 2. **Workaround using two feeds:**
>    - **Feed 1** (with lowest price option ON): Add a Rules & Filters entry to exclude the exception product: `Product ID is equal to [ID]` → Skip product. This feed handles all other products normally.
>    - **Feed 2** (without lowest price option): Use the "Include variations" option. Add a rule to include ONLY the exception product: `Product ID is equal to [ID]` → Include. This feed outputs all variations for that one product.
> 3. Submit both feeds to the relevant ad platform (Google, Meta, etc.).
> 4. **PMax note:** Google PMax campaigns can only use one feed per campaign. If the customer needs all products in a single PMax feed, the two-feed approach won't work for that use case. Raise as a feature request.
> 5. **Alternative — PHP snippet** to exclude specific products from all feeds entirely (if the goal is simply to remove them):
>
> ```php
> add_filter( 'adt_get_product_data', function( $product_data, $feed ) {
>     $exclude_ids = array( 123, 456 ); // Replace with product IDs
>     if ( isset( $product_data['id'] ) && in_array( (int) $product_data['id'], $exclude_ids, true ) ) {
>         return array();
>     }
>     return $product_data;
> }, 10, 2 );
> ```
