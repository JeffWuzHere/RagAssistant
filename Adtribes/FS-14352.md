# Knowledge Base Entry: Google product category not reflecting primary WooCommerce category — plugin picks first category found

## 🎯 Executive Summary
**The Issue:** Products assigned to multiple WooCommerce categories were appearing under the wrong Google product category and product_type in the feed because the plugin picks the first category it encounters, not the WooCommerce "primary category."
**The Fix:** Use Rules and Filters on the **Category path** field to explicitly override which category path appears in the feed; additionally, a hotfix version was provided to resolve category rules not applying correctly.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** Google product category wrong, category mapping not working, product type wrong category, primary category not used, rank math primary category blank, category hierarchy mismatch, first category picked
>
> **Steps to solve:**
> 1. Clarify the two separate category fields in the feed:
>    - **Google product category** — resolved through the manual mapping table; picks category based on the mapping table order.
>    - **product_type / Category path** — pulls the raw WooCommerce category hierarchy; picks the "first" category the plugin sees, which may not be the WooCommerce primary category.
> 2. For Google product category issues: review the manual mapping table and adjust the category list order so the desired category maps correctly.
> 3. For product_type/Category path issues: use **Rules and Filters** on the **Category path** field to override and force the correct category path for affected products or categories.
> 4. Note: the Rank Math "primary category" option in the plugin may not work as expected in all configurations — if it shows blank, fall back to rules and filters instead.
> 5. If category rules are not applying correctly, check if the customer is on the latest plugin version. A hotfix was released addressing category rules not working as intended.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- The plugin does not natively read the WooCommerce "primary category" setting or Rank Math's primary category — it picks the first category in the product's assigned category list. This is a known limitation.
- The mapping table order matters: the plugin resolves the Google product category by going through the mapping rows in order and applying the first match. Re-ordering rows can change which Google category gets assigned.
- If a customer says the Rank Math primary category option shows blank, the integration may require a specific version of Rank Math or plugin — do not spend time debugging this; direct them to the Rules and Filters workaround instead.
- A hotfix addressing category rules was in circulation around this period — confirm the customer is on the latest release before troubleshooting rules logic.
