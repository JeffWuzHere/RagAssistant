# Knowledge Base Entry: How to map ACF custom fields to feed attributes (e.g., Customs Tariff Number to MPN)

## 🎯 Executive Summary
**The Issue:** Customer wanted to map an ACF custom field value (e.g., "Customs Tariff Number" at variation level) to a standard feed attribute like MPN.
**The Fix:** Custom fields (including ACF) appear in the field value dropdown in Field Mapping after clearing the Custom Attribute Cache. Simply search for the field name and map it to the desired attribute.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** ACF field not showing in mapping, custom field not appearing in feed, how to map ACF to MPN or GTIN, custom attribute mapping, variation custom field in feed
>
> **Steps to solve:**
> 1. Go to Product Feed > Settings and click **Clear Custom Attributes Cache**. This forces the plugin to re-index all available product fields, including ACF.
> 2. Open the feed and go to the **Field Mapping** tab.
> 3. In the attribute row for the target feed attribute (e.g., MPN), click the value dropdown on the right side.
> 4. Search for the ACF field name. For variation-level ACF fields, the field will appear with its full label or ACF key.
> 5. Select it and save.
> 6. Regenerate the feed and verify the custom field values are now appearing in the correct attribute column.
> 7. For **Rules & Filters**: the same field name (as shown in the mapping value column) can be used as the target in rule conditions.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- If a custom field doesn't appear in the dropdown after clearing the cache, it may be because: (a) no products currently have a value set for that field, or (b) the field is defined in ACF but not saved on any products yet.
- Variation-level ACF fields appear separately from parent product fields. Look for both when the customer has variation-specific data.
- Rules can only reference fields that are visible in the mapping value dropdown — so clearing the custom attribute cache is always the first step before diagnosing "my field isn't working in rules."
