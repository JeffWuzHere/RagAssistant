# Knowledge Base Entry: TranslatePress feed reverting to default language on automatic refresh — hotfix and fixed in v5.0.5

## 🎯 Executive Summary
**The Issue:** Feeds configured for a non-default language (e.g., French) with TranslatePress were outputting the default site language (e.g., Italian/English) after one or more automatic refreshes.
**The Fix:** This was a known bug. A hotfix ZIP was provided as an interim fix. The permanent fix shipped in **Product Feed Elite v5.0.5**.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** TranslatePress feed wrong language, feed switching back to default language, translated feed showing original language, TranslatePress language not working on auto refresh, feed language reverts after scheduled refresh
>
> **Steps to solve:**
> 1. Confirm the customer is using **TranslatePress** (not WPML or CURCY).
> 2. Ask them to update **Product Feed Elite to v5.0.5 or later** — the bug was fixed in that release.
> 3. After updating, create a new feed (or duplicate the existing one) for the target language, set the language on the General tab, and activate it.
> 4. Refresh the feed 2–3 times and verify the language in the XML output.
> 5. If they are on v5.0.5+ and still see incorrect language, check for caching plugins (LiteSpeed Cache, WP Rocket, Wordfence) that may be interfering — see FS-6418 for that scenario.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- This bug was specific to **automatic/scheduled** feed refreshes — the language setting was being dropped during the background generation process. Manual refreshes were also sometimes affected after multiple cycles.
- The fix in v5.0.5 properly persists the language setting throughout the feed generation pipeline.
- If a customer on v5.0.5+ still has language issues with TranslatePress, the likely culprit is a caching or security plugin intercepting the feed generation request (see FS-6418).
- Related GitHub issue: https://github.com/Rymera-Web-Co/woo-product-feed-elite/issues/305
