# Knowledge Base Entry: Custom/Awin feed template returning no products — 'Include Variations' option not enabled on a store with only variable products

## 🎯 Executive Summary
**The Issue:** A custom feed template (Awin UK) was generating an empty CSV — no products were returned at all. The store had no simple products; all products were variable. Because the "Include Variations" option was not enabled on the feed, and there were no simple products to include, the feed output was empty.
**The Fix:** Enable the **Include Variations** (or "Include Product Variations") option in the feed's General Settings. On stores that sell only variable products (no simple products), this option must be on or the feed will always be empty.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** Awin feed empty, custom feed template no products, feed returning no results, CSV feed empty, feed generating but no output, all product feeds empty, variable product feed empty, only variable products feed not working
>
> **Steps to solve:**
> 1. Open the affected feed and go to **General Settings**.
> 2. Locate the **Include Product Variations** (or "Include Variations") toggle and confirm whether it is enabled.
> 3. If the option is OFF and the store sells only variable products (no simple products): this is the cause. Enable it.
> 4. Save and manually **Refresh** the feed.
> 5. Open the feed output file (CSV or XML) and confirm products are now present.
> 6. If the store has a mix of simple and variable products and only variations are missing, enabling this option will add them — existing simple products are unaffected.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- By default, feed generation includes simple products. Variable products are included only when "Include Product Variations" is explicitly enabled. On stores where all products are variable, this means the default configuration will always produce an empty feed.
- This is a common misconfiguration, especially for stores that migrated from simple to variable products after their feeds were set up — the feeds were working when there were simple products, then became empty after the catalog changed.
- Enabling "Include Variations" outputs one feed row per variation, not one row per parent product. This is the correct behavior for most ad channels (Google Shopping, Awin, etc.) which require variation-level listings for products with size/color attributes.
- If the feed is empty but "Include Variations" is already on, the next check is Rules & Filters — a rule may be excluding all products (see FS-13865, FS-6034).
