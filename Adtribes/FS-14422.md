# Knowledge Base Entry: Varle.lt XML image structure not supported — images tag requires nested image elements

## 🎯 Executive Summary
**The Issue:** A customer generating an XML feed for Varle.lt marketplace found the plugin outputs `<images></images>` (empty or flat structure) while Varle.lt requires `<images><image>...</image></images>` with each image wrapped in a nested `<image>` tag.
**The Fix:** Varle.lt is not a supported marketplace in the plugin; there is no workaround via custom snippet. A feature request was raised in GitHub.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** Varle.lt feed, nested image tags, images element structure XML, images tag empty, Varle.lt integration, Lithuanian marketplace
>
> **Steps to solve:**
> 1. Confirm that Varle.lt is not currently a supported marketplace in Product Feed Pro/Elite.
> 2. Explain that the specific `<images><image>` nested XML structure required by Varle.lt cannot be configured through the plugin's current settings and there is no custom snippet workaround.
> 3. Offer to raise or upvote the feature request. Reference GitHub issues: `woo-product-feed-pro#904` and `woo-product-feed-elite#19`.
> 4. Inform the customer there is no ETA for when this marketplace will be added.
