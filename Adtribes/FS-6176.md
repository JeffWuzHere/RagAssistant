# Knowledge Base Entry: Google Shopping .txt feed quoting comma-separated image URLs as a single value — fix by changing delimiter to pipe (|)

## 🎯 Executive Summary
**The Issue:** A Google Shopping `.txt` format feed was outputting `additional_image_link` URLs as a quoted comma-separated string (`"url1,url2,url3"`). Because the entire value was quoted, Google treated the comma-delimited list as a single URL rather than multiple images.
**The Fix:** Change the feed delimiter from comma (`,`) to pipe (`|`) in the AdTribes feed settings, and update the matching delimiter setting in Google's Advanced Data Feed settings. This prevents the CSV quoting behavior that causes commas inside values to wrap the whole field in quotes.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** additional_image_link quoted in txt feed, images treated as single URL, comma-separated images not working Google, quoted image URLs Google Shopping, txt feed image link problem, CSV delimiter additional images
>
> **Steps to solve:**
> 1. Open the feed settings in AdTribes and go to **Advanced Settings** (or the delimiter field in General settings).
> 2. Change the **Delimiter** from comma (`,`) to **pipe** (`|`).
> 3. Save the feed and refresh it.
> 4. In Google Merchant Center, open the data feed's **Advanced Settings** (this section is collapsed by default in the feed setup wizard).
> 5. Update the delimiter there to match: **pipe** (`|`).
> 6. If Google also has a "Quoted Fields" or similar option, adjust it to match the new format.
> 7. Trigger a re-sync in Google Merchant Center and verify the images are now loading correctly (multiple images, not a single broken URL).

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- This is a standard CSV quoting behavior: when a comma (`,`) is the delimiter and a field value contains a comma, the value gets wrapped in double quotes. Google's parser then sees the whole quoted string as one value.
- Using pipe (`|`) as the delimiter avoids this problem because image URLs never contain pipes.
- The fix must be applied in **both places**: the AdTribes feed delimiter AND the Google Merchant Center feed Advanced Settings. Changing only one side will cause a format mismatch.
- Google's Advanced Settings section for data feeds is collapsed by default in the GMC setup wizard — customers often don't know it exists. This is where quoted field behavior and delimiter are configured on Google's side.
- This issue only affects `.txt` (TSV/CSV) format feeds. XML format feeds (`additional_image_link_b`, `_c`, etc.) have a different pattern — see FS-11423.
