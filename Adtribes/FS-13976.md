# Knowledge Base Entry: GTIN missing for WPC Composite Products — PHP snippet to read GTIN from composite product type

## 🎯 Executive Summary
**The Issue:** GTIN values are not appearing in the feed for WPC Composite Products (by WPClever), because Product Feed Pro/Elite natively reads GTIN only from `simple` and `variation` product types — the `composite` type is not handled.
**The Fix:** Add a PHP snippet that hooks into `adt_get_product_data` to manually read the WooCommerce GTIN field for composite products and inject it into the feed data.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** GTIN missing for composite products, WPC Composite Products GTIN, global unique ID not showing, EAN/UPC blank for composite product type
>
> **Steps to solve:**
> 1. Confirm the product type is `composite` (from WPC Composite Products by WPClever or similar).
> 2. Add the following snippet to the child theme's `functions.php` or via the WP Code plugin:
>
> ```php
> add_filter( 'adt_get_product_data', function( $product_data, $feed ) {
>     if ( empty( $product_data['global_unique_id'] ) ) {
>         $product_id = $product_data['id'] ?? 0;
>         if ( $product_id ) {
>             $gtin = get_post_meta( $product_id, '_global_unique_id', true );
>             if ( $gtin ) {
>                 $product_data['global_unique_id'] = $gtin;
>             }
>         }
>     }
>     return $product_data;
> }, 10, 2 );
> ```
>
> 3. Regenerate the feed and confirm GTIN values are now appearing for composite products.
> 4. If `_global_unique_id` is not the correct meta key for their setup, ask the customer to check what field they use to store GTIN on composite products (it may be a custom field or the WooCommerce built-in Inventory tab field).
