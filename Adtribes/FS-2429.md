# Knowledge Base Entry: WooCommerce Product Bundles + Aelia Currency Switcher showing price 0 in feed — development fix required

## 🎯 Executive Summary
**The Issue:** Products using the **WooCommerce Product Bundles** extension (official WooCommerce extension) were showing a price of `0` in the feed when **Aelia Currency Switcher** was also installed. Simple and variable products were unaffected — only bundles with variable product components showed the zero-price bug.
**The Fix:** A bug in the plugin's price retrieval logic for Product Bundles + Aelia was identified. A development fix was shipped — update Product Feed Elite to the latest version which includes the fix (submitted as a GitHub PR after the ticket).

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** bundled product price 0, product bundle showing zero price in feed, WooCommerce bundles price wrong, bundle feed price not showing, Aelia bundle price issue, product bundle feed empty price
>
> **Steps to solve:**
> 1. Confirm the customer is using both **WooCommerce Product Bundles** (the official WooCommerce extension) AND **Aelia Currency Switcher**.
> 2. Confirm the price 0 only affects bundle products, not simple or standard variable products.
> 3. Update **Product Feed Elite** to the latest version — the fix was merged as a PR and included in a subsequent release.
> 4. After updating, manually refresh the feed and verify bundle prices are now correctly populated.
> 5. If the customer is on a very recent version and still sees the issue, escalate to the development team with staging site access.

## 💡 Internal Insights (If applicable)

- This bug specifically requires the combination of WooCommerce Product Bundles (the premium WooCommerce extension) + Aelia Currency Switcher. Either plugin alone does not trigger the issue.
- Updating Aelia Foundation Classes alone is NOT the fix for this issue — the fix is in the AdTribes Product Feed Elite plugin itself.
