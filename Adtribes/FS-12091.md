# Knowledge Base Entry: Feed stuck at 0% due to disabled Action Scheduler; hook priority for adt_get_product_data

## 🎯 Executive Summary
**The Issue:** Feeds were stuck at 0% and not generating. Root cause: WooCommerce Action Scheduler / scheduled tasks were disabled. Secondary issue: `adt_get_product_data` hook was being overridden by the feed's field mapping — fix by raising priority to 999.
**The Fix:** Re-enable WooCommerce scheduled actions. For hook overrides, use priority 999 or switch to `adt_product_feed_xml_attribute_value` for XML-specific modifications.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** feed stuck at 0% not starting, feed generation not beginning, scheduled tasks disabled, adt_get_product_data hook overridden by mapping, hook not working, field mapping overrides custom code, additional variation images in feed
>
> **Steps to solve:**
> **For feed stuck at 0%:**
> 1. Ask the customer to go to WooCommerce > Status > Scheduled Actions and check if scheduled actions are enabled/running.
> 2. If scheduled actions are disabled or paused, re-enable them.
> 3. Try generating the feed again. If it still doesn't start, check for any plugin conflicts disabling the Action Scheduler.
>
> **For adt_get_product_data hook being overridden:**
> 1. The feed's field mapping runs after `adt_get_product_data` at its default priority (10), which means mapping values can overwrite custom hook values.
> 2. Raise the priority to 999: `add_filter('adt_get_product_data', 'your_function', 999, 2);`
> 3. Alternatively, for XML feed output specifically, use `adt_product_feed_xml_attribute_value`:
>
> ```php
> add_filter( 'adt_product_feed_xml_attribute_value', function( $v, $k, $product, $value, $feed ) {
>     if ( $k === 'g:title' ) { // Replace with your attribute key
>         return 'your_custom_value';
>     }
>     return $v;
> }, 10, 5 );
> ```
>
> **For additional variation images:**
> 1. Add the `additional_image` mappable fields in Field Mapping.
> 2. For a Google feed using `.txt` format, map a single `additional_image_link` attribute and output multiple URLs comma-separated.

- The execution order is: `adt_get_product_data` (default priority 10) → Field mapping → `adt_product_feed_xml_attribute_value`. So `adt_get_product_data` at priority ≤ 10 will be overwritten by mapping; at 999 it runs after mapping and wins.
- `adt_product_feed_xml_attribute_value` only fires for XML format feeds, not CSV/TXT.
