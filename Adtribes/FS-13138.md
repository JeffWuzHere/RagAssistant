# Knowledge Base Entry: Very old plugin version (1.2.7) not receiving update notifications — upgrading to v5.0.6 auto-migrates existing feeds

## 🎯 Executive Summary
**The Issue:** Customer on Product Feed Elite v1.2.7 (purchased ~5 years ago via guest checkout) was not seeing any update notifications and had an unverifiable/expired license. Wanted to know if they could update without losing existing feeds.
**The Fix:** Purchase a new subscription, install v5.0.6, and do a manual refresh — existing feeds automatically migrate. No need to recreate them.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** no update notifications showing, plugin stuck on very old version, version 1.x or 2.x or 3.x of Elite, HPOS compatibility, license not found, guest checkout purchase years ago, will I lose my feeds if I update
>
> **Steps to solve:**
> 1. Confirm the current version. If they are on v1.x, v2.x, or v3.x, their license is almost certainly expired (licenses are subscription-based).
> 2. If the customer cannot find their license: check their email in the Rymera/adtribes.io system. Guest checkout purchases from years ago may have incomplete records.
> 3. If the license is expired or unverifiable, the customer will need to purchase a new subscription at https://adtribes.io/pricing/
> 4. Direct them to download the latest zip from https://adtribes.io/my-account/ after purchase.
> 5. Install the latest Product Feed Elite. **Existing feeds will auto-migrate** on the next manual refresh — no need to recreate.
> 6. If the customer wants to be cautious: duplicate each feed first, then update and confirm the originals migrated correctly before deleting the duplicates.
> 7. Note: v5.0.6 includes HPOS support and all modern WooCommerce compatibility fixes.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- Customers on extremely old versions (1.x) will never see update notifications because their license is inactive — WordPress update checks for premium plugins require a valid, active license key.
- Feed migration on version update is automatic and triggered by the first manual refresh after update. No manual database migration steps are needed.
- Guest checkout purchases from 5+ years ago can be hard to trace; license keys may not match the email on file. Always check both the email and the license key field separately in the admin system.
