# Knowledge Base Entry: Feed error when Multicurrency plugin is installed but 'Enable Multi-Currency' option is not toggled on in Product Feed Elite settings

## 🎯 Executive Summary
**The Issue:** A feed was showing a "Feed failed to upload" error. The site had a Multicurrency plugin installed (WooCommerce Multilingual / WPML Multi-Currency), but the corresponding multi-currency toggle in Product Feed Elite settings was not enabled.
**The Fix:** Go to **Product Feed Elite > Settings** and enable the **Enable Multi-Currency** (or "Multicurrency") option. After enabling, refresh the feed.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** feed error with multicurrency, feed failed to upload multicurrency, multi-currency feed not working, currency plugin installed but feed errors, WPML multicurrency feed error, enable multi-currency setting
>
> **Steps to solve:**
> 1. Confirm the customer has a Multicurrency or WooCommerce Multi-Language + currency plugin installed (e.g., WPML Multicurrency / WooCommerce Multilingual).
> 2. Go to **Product Feed Elite > Settings**.
> 3. Locate the **Multi-Currency** (or "Multicurrency") toggle option and enable it.
> 4. Save the settings.
> 5. Ensure the correct currency is configured in the feed's General settings.
> 6. Refresh the feed and verify the error is resolved.
> 7. Note: enabling this option has no negative impact on site performance — it only activates the currency conversion integration.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- This is a case where the presence of a Multicurrency plugin without the corresponding toggle enabled in Product Feed Elite causes an internal conflict — the plugin detects the currency infrastructure but cannot interact with it correctly.
- The error manifests as a generic "Feed error" or "Feed failed to upload" status — not obviously related to currency settings.
- After the bug fix was released, this should have been resolved automatically. However, if a customer on an up-to-date version still sees this, try cycling the toggle (disable and re-enable) as a first step.
- This is separate from currency conversion issues (e.g., prices not converting) — those are diagnosed via FS-11519 (unsupported currency switcher) or FS-5746 (WPML/WCML setup).
