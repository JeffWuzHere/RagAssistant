# Knowledge Base Entry: PHP Warning: Undefined array key 's' in bootstrap-old.php — fixed in v13.5.1

## 🎯 Executive Summary
**The Issue:** Sites running PHP 8.x were generating repeated PHP warnings: `Warning: Undefined array key "s" in .../woo-product-feed-pro/bootstrap-old.php on line 358`.
**The Fix:** This was a known bug fixed in Product Feed Pro **v13.5.1**. Update to v13.5.1 or later to resolve it.

---

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- This warning appears on PHP 8.x because PHP 8 changed behavior for undefined array keys (previously silently returned `null`, now triggers a warning).
- The warning originates in `bootstrap-old.php` — a legacy compatibility layer. The fix likely adds a proper `isset()` check.
- The warning is non-fatal: feeds will still generate, but error logs may fill up quickly with repeated entries.
- If a customer is on v13.5.0 and cannot update yet, and the warning is causing log bloat, they can temporarily suppress it via `error_reporting` in `wp-config.php` — but this is a last resort.
