# Knowledge Base Entry: Aelia Currency Switcher showing wrong prices in USD feed — stale currency data retained in old feed

## 🎯 Executive Summary
**The Issue:** After adding USD as a third currency (EUR base, GBP and USD added), the GBP feed was correct but the USD feed showed prices lower than the actual converted price. The feed itself was retaining stale currency data from before the USD currency was added.
**The Fix:** Update all plugins, then **recreate the feed** for the currency showing incorrect prices. Old feeds can cache bad currency conversion data that persists even after plugin updates.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** Aelia Currency Switcher wrong prices in feed, currency conversion incorrect in feed, feed showing old prices after adding new currency, USD feed price mismatch, GBP correct but other currency wrong
>
> **Steps to solve:**
> 1. Confirm the customer is using Aelia Currency Switcher (supported) vs an unsupported plugin.
> 2. Ask the customer to update all plugins to the latest versions — both Product Feed Pro and Elite.
> 3. **Do not** try to fix the existing feed in-place. The feed retains stale currency conversion data that does not update automatically.
> 4. On the live site, recreate the currency feed from scratch (or duplicate the working GBP feed and change the currency setting to USD/the failing currency).
> 5. Set the correct currency in the feed's General settings.
> 6. Manually refresh the new feed and view the XML via incognito to confirm prices are converting correctly.
> 7. Update the feed URL in Google Merchant Center or the relevant ad platform.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- This is case-by-case and not 100% replicable, but the pattern is consistent: old feeds retain the currency conversion state at the time of feed creation. When a new currency is added later, the existing feed does not re-initialize for the new currency settings.
- Simply refreshing the feed does not clear the stale currency data — the feed object must be recreated.
- Duplicate plugin menu entries (e.g., two "License" entries) indicate a corrupted or double-installed plugin state. Triggered by partial plugin updates or FTP uploads on top of an existing install. Fix: clean uninstall + fresh install.
- Aelia Currency Switcher is a supported integration: https://adtribes.io/aelia-currency-switcher-feature/
