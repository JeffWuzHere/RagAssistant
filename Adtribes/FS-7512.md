# Knowledge Base Entry: Preview feed empty when filters don't match first 5 products; duplicated feeds start as Inactive; CURCY link suffix required

## 🎯 Executive Summary
**The Issue:** Three distinct issues in one ticket: (1) preview mode shows 0 products when the filter criteria don't match any of the first 5 products in the database; (2) a duplicated feed defaults to "Inactive" status and produces no output; (3) CURCY Currency Switcher requires a link suffix to be set or product URLs will point to the wrong currency.
**The Fix:** (1) Bug fixed in v13.5.1 — disable Product Preview as a workaround on older versions. (2) Manually activate the duplicated feed before refreshing. (3) Add `&wmc-currency=XXX` suffix to the feed's Link field.

---

## 🛠 Final Resolution (The "2nd Me" Guide)
> [!TIP]
> **Use this solution if a customer asks about:** preview feed empty, preview mode showing 0 products, product preview not working, duplicated feed empty, copy of feed not showing products, CURCY feed link wrong currency, include variations empty feed
>
> **Steps to solve:**
> **Issue 1 — Preview feed returns 0 products:**
> 1. Confirm the customer's filters are active on the preview feed.
> 2. Update to **Product Feed Pro v13.5.1** — the bug (preview empty when rules/filters don't match first 5 products) was fixed there.
> 3. As a workaround on older versions: disable the **Product Preview** option on the feed settings. The full feed will generate correctly even without preview mode.
>
> **Issue 2 — Duplicated/copied feed showing 0 products or not refreshing:**
> 1. After duplicating a feed, the copy defaults to **Inactive** status.
> 2. Click the "Inactive" badge in the feed list to toggle it to **Active**.
> 3. Then manually refresh the feed — only active feeds generate output.
>
> **Issue 3 — CURCY Currency Switcher link suffix:**
> 1. If using the **CURCY (WooCommerce Multi Currency)** plugin, product URLs in the feed must include the currency parameter.
> 2. On the feed's Field Mapping, find the **Link** field and add suffix: `&wmc-currency=XXX` (where `XXX` is the 3-letter currency code, e.g., `AUD`, `GBP`).
> 3. Ensure the currency selected in the feed's General settings matches the suffix.
> 4. See: https://adtribes.io/curcy-currency-switcher-feature/
>
> **Also check:** If the feed returns 0 products with no preview and no obvious rules, confirm that **Include Product Variations** is enabled if the store has variable products — simple products alone may be too few.

## 💡 Internal Insights (If applicable)
*This section contains logic extracted from internal notes or agent-to-agent talk.*
- The preview bug: preview mode only checks the first 5 products in the database. If none of those 5 match the active filters, it returns 0. The fix in v13.5.1 corrects the logic so preview properly samples matching products.
- Duplicated feeds defaulting to Inactive is by design — to prevent accidentally activating a half-configured copy. Always remind customers to activate the copy after duplication.
- CURCY link suffix is documented at https://adtribes.io/curcy-currency-switcher-feature/ — if the suffix is missing, Google and other platforms may show price mismatch errors because the landing page shows the default currency, not the one in the feed.
- Related GitHub issue for the preview bug: https://github.com/Rymera-Web-Co/woo-product-feed-pro/issues/727
